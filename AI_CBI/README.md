# AI CBI 채팅

채팅 영역, 메시지 상자, 전송 버튼을 갖춘 브라우저 채팅 웹 앱입니다. 별도 빌드 없이 HTML, CSS, JavaScript만으로 동작합니다.

> 현재 AI 답변은 화면 동작을 보여 주는 **데모 문구**입니다. 실제 AI 모델이나 백엔드 API는 연결되어 있지 않습니다.

## 실행

### 파일로 열기

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 다만 `file://` 주소에서는 마이크 권한 요청이 반복될 수 있습니다.

### localhost로 실행 (권장)

Node.js가 설치되어 있다면 로컬 서버로 실행할 수 있습니다.

- VS Code: **Terminal → Run Task → `AI_CBI: Run on localhost`**
- 터미널: 저장소 루트에서 `node AI_CBI\serve.mjs`

실행 후 <http://localhost:4173>에서 이용합니다. 서버를 종료하면 주소 연결이 거부되므로 필요할 때 다시 실행하세요.

## 기능

- 메시지 입력 후 **전송** 버튼 또는 `Enter`로 보내고, `Shift + Enter`로 줄바꿈합니다.
- 사용자와 AI 메시지 옆에 각각 구분되는 원형 아바타가 표시됩니다.
- 답변이 오기 전에는 점 세 개 입력 중 표시가 나타나고, 이후 답변이 단어 단위로 스트리밍됩니다.
- 모든 대화와 답변이 브라우저 `localStorage`에 저장되며, 왼쪽 **저장된 대화** 목록에서 다시 열 수 있습니다.
- **새 대화** 버튼으로 새 대화를 시작해도 기존 기록은 유지됩니다.
- AI 답변에서 제목, 굵게·기울임, 목록, 인용문, 링크, 인라인 코드, 코드 블록 등 기본 마크다운을 렌더링합니다. HTML은 실행되지 않고 텍스트로 표시됩니다.
- 마이크 버튼으로 Web Speech API 한국어 음성 입력을 사용할 수 있습니다. 인식된 내용은 입력창에 표시되므로 확인한 뒤 전송합니다.
- 모바일 화면과 키보드 사용을 고려한 반응형 레이아웃입니다.

## 저장 방식

대화는 `localStorage`의 `ai-cbi-conversations` 키에 저장됩니다.

- 데이터는 해당 브라우저와 **주소(origin)별**로 저장됩니다. `file://`로 열었을 때와 `http://localhost:4173`에서 연 기록은 서로 보이지 않습니다.
- 브라우저의 사이트 데이터를 삭제하면 기록도 삭제됩니다.
- 저장된 데이터가 손상되었거나 저장 공간이 부족하면 화면에 오류를 표시하고, 기존 데이터를 덮어쓰지 않도록 저장을 중단합니다.

## 음성 입력 안내

- Chrome 또는 Edge 같은 Web Speech API 지원 브라우저가 필요하며, 마이크 권한을 허용해야 합니다.
- 음성 인식은 브라우저의 음성 서비스에 의존합니다. 네트워크 오류가 나면 인터넷 연결과 권한을 확인하세요.
- VS Code 내장 브라우저에서는 마이크 권한이나 음성 인식이 지원되지 않을 수 있습니다. 음성 입력은 Chrome에서 사용하는 것을 권장합니다.
- 마이크 권한은 마이크 버튼을 눌렀을 때만 요청되며, 일반 타이핑으로는 요청되지 않습니다.

## 파일 구조

- `index.html`: 화면 구조
- `styles.css`: 화면 스타일
- `app.js`: 메시지 전송, 스트리밍, 대화 저장, 마크다운 렌더링, 음성 입력
- `serve.mjs`: 추가 설치 없이 localhost로 실행하는 간단한 정적 서버
- `../.vscode/tasks.json`: VS Code 실행 작업

## 실제 AI 연결하기

`app.js`의 `DEMO_REPLY`와 `startReply`가 현재 데모 응답을 만듭니다. 실제 모델을 연결하려면 이 부분을 백엔드 API 호출로 바꾸고, 응답 토큰을 받을 때마다 답변 메시지 텍스트에 이어 붙여 렌더링하세요. API 키는 브라우저 코드에 넣지 말고 서버에서 관리해야 합니다.

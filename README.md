# 오늘의 할 일

브라우저에서 바로 실행하는 간단한 할 일 관리 앱입니다. 별도 설치나 빌드 과정 없이 `TODOLIST/index.html`을 열어 사용할 수 있습니다.

## 사용 방법

- 입력창에 할 일을 적고 **추가**를 눌러 등록합니다.
- **새 목록 이름**을 입력하고 **목록 추가**를 눌러 목록 공간을 만들 수 있습니다. 목록 탭의 휴지통 버튼으로 삭제하며, 마지막 목록은 삭제할 수 없습니다.
- 목록 탭을 눌러 전환하면 각 목록의 할 일이 따로 표시됩니다.
- 체크 표시를 눌러 완료 상태를 바꿉니다.
- **전체**, **진행 중**, **완료** 필터로 목록을 전환합니다.
- 휴지통 버튼으로 항목 하나를 삭제하거나 **완료 항목 모두 삭제**로 완료된 작업을 한 번에 지웁니다.
- 남은 작업 수와 전체 완료율은 목록 변경에 따라 자동으로 갱신됩니다.

## 저장 방식

작업 목록은 브라우저의 `localStorage`에 저장되며, 새로 고침해도 유지됩니다. 데이터는 해당 브라우저에 저장되므로 다른 브라우저나 기기와 자동으로 동기화되지는 않습니다.

## 포트폴리오 페이지

개인 포트폴리오 예시는 `portfolio.html`에서 확인할 수 있습니다. 이름과 연락처, 프로젝트 소개를 실제 정보로 바꾸고 브라우저에서 파일을 열어 사용하세요. 문의 양식은 기본 메일 앱을 열며, 연결 이메일은 HTML 파일의 `hello@example.com`을 수정하면 됩니다.
